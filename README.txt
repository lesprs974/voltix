RIDEUP — site e-commerce de démonstration

1. Ouvre index.html dans un navigateur.
2. Les 3 photos envoyées sont déjà intégrées.
3. Les prix affichés sont provisoires : 9,90 €, 7,90 € et 19,90 €.
4. Le panier fonctionne en local.
5. Le bouton Commander est une démo : pour de vraies ventes, connecte Stripe/PayPal ou ton système de paiement.

Pour modifier les produits/prix : ouvre index.html et cherche le nom ou le prix.
